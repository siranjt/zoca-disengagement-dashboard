Three states only

Logging a call: the 3-state flow

✓

Connected

You spoke with them. Pick a reason: renewal, performance, billing, check-in, escalation, other.

Default · 80% of calls
VM

Voicemail

You left a message. Set a 7-day follow-up by default — or shorter if urgent.

VM ≠ no-reach. Partial touch.
×

No reach

Couldn't get hold. Auto-schedules a retry. Triggers a 'no-reach streak (3+)' coaching loop after the third attempt.

Log it. Coach sees the pattern.
Zoca · AM KT · 202613 / 28
The single biggest mistake: marking a VM as no-reach. They mean different things. VM is a partial touch. No-reach = total miss.

Watch for these

Common gotchas

!Notes are PRIVATE.

Don't put anything you'd be embarrassed for your manager to see — but also nothing they NEED to see. Use the action log's reason codes for structured handoff.

!Snoozes don't text the customer.

Set a calendar reminder if you need the snooze to drive an outreach. The dashboard just hides them — it doesn't auto-DM.

!0 customers today?

Congrats! Use the 'Watch' filter to be proactive. YELLOW customers are tomorrow's RED if no one talks to them.

!The orange staleness banner is real.

If you see 'Snapshot is 24h ago', click Refresh — don't work the list before the data updates.
